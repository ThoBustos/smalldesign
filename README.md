# small.design

React prototypes for three possible small.design directions:

- `Signal`: oversized editorial type, blue system band, hard service/contact grid.
- `Index`: minimalist proof-led office with a black specimen board.
- `System`: product-aware identity direction for software teams.

Run with:

```bash
npm install
npm run dev
```

Verify with:

```bash
npm run build
npm run screenshots
```
